        CHINESE

        一键中文

        AI 检查 Codex 和 Claude 的界面语言和回复语言，把还不是中文的项改成简体中文。用的是客户端自带的语言设置，不改程序文件。改完后完全退出客户端（托盘里的也要退出）再打开。

        手动设置
        • Codex 桌面版界面config.toml [desktop] localeOverride = "zh-CN"
        • Codex 回复语言在全局 AGENTS.md 里要求用简体中文回复
        • Claude 桌面版界面config.json locale = "zh-Hans"，需要先退出 Claude 桌面版
        • Claude Code 回复语言settings.json language = "Simplified Chinese"

        Claude Code 命令行界面本身没有中文版，这里设置的是它的回复语言。

            FAQ

            桌面版白屏

            白屏没有可靠的一键修复，下面是检查方法。界面改中文请用「一键中文」。

            1. 从托盘完全退出客户端，再重新打开。
            2. 运行「一键检测」看「本机代理」：系统代理开着但代理软件已经关了，桌面版会一直白屏。打开代理软件，或在系统设置里关掉代理。
            3. 客户端代理指向没在监听的端口时，检测结果里会有「清除代理」按钮。
            4. 仍然白屏：重新安装客户端（Windows 上同时更新 Microsoft Edge WebView2）。
